# Богатырский Буст — бэкенд-ядро

AI-инструмент маркетинга и автоматизации для микро- и малого бизнеса (Новороссия + РФ).
Платформа из 4 модулей; этот репозиторий — **бэкенд-ядро** на NestJS (адаптер Fastify).

Первый срез заложен: **фундамент + entitlement-ядро** — тарифы как конфигурируемый
entitlement-конфиг и feature-flag слой, проверяемый сквозным образом.

## Архитектура

4 продуктовых модуля — изолированные домены (`src/modules/*`), каждый закрыт своим
feature-flag по тарифу с первого компонента:

1. **`site-builder`** — Конструктор сайтов/лендингов (`Feature.SiteBuilder`, только Богатырский).
2. **`content`** — Генератор контент-стратегий/медиа (`Feature.ContentGeneration`).
3. **`automation`** — AI-автоматизация и автопостинг (`Feature.Autoposting`, `Feature.Multichannel`).
4. **`analytics`** — Аналитика воронок и метрик (`Feature.Analytics`).

Ядро тарифов/прав — `src/billing` (глобальный модуль):

- **`tariff-catalog.config.ts`** — единственный источник правды по возможностям и лимитам.
  Меняешь тариф — правишь конфиг, а не логику модулей.
- **`EntitlementService`** — единственное место, где код спрашивает «можно ли»:
  `hasFeature`, `getLimit`, `assertFeature`, `assertWithinLimit`, `consume`, `getRemaining`.
- **`EntitlementGuard` + `@RequireFeature`** — декларативный гейтинг маршрутов по тарифу.
- **Порты** (`UsagePort`, `SubscriptionResolverPort`) — реализации (in-memory, dev-резолвер
  по заголовку) подменяются на продовые без правок бизнес-логики.

### AI-шлюз

Все вызовы LLM/генерации идут через `AiGatewayPort` (`src/ai-gateway`), чтобы менять
провайдера без правок модулей и встроить 152-ФЗ-прослойку.

- **Роутинг задача→модель** (`ai-routing.config.ts`, spec п.4): базовый текст → YandexGPT 5
  Lite, сложный → GigaChat Ultra, изображения → Kandinsky.
- **Транспорт выбирается на старте**: задан `AI_GATEWAY_URL` → HTTP-шлюз (KodikRouter /
  ITGLOBAL AIaaS, маршрутизация без передачи данных за рубеж); иначе — локальный фолбэк,
  который честно отдаёт структурные заготовки (не выдаёт себя за AI), чтобы модуль контента
  работал в dev без секретов.
- Текст реализован; генерация изображений (Kandinsky) — отдельный срез.

Модуль контента (`src/modules/content`) владеет промпт-инжинирингом и пресетами форматов
(`content-presets.ts`: короткое видео / карусель / stories / отзыв — spec п.6), а генерацию
делегирует шлюзу. Лимит генераций списывается по факту успеха (assert → generate → record),
чтобы не штрафовать за упавший вызов AI.

### Автопостинг (`src/posting`)

Публикация идёт ТОЛЬКО через очередь с rate-limiter (spec п.8), без синхронных вызовов.
Модуль автоматизации (`src/modules/automation`) ставит пост в `PostingQueuePort`, а домен
`posting` проводит каждый канал через цепочку:

- **rate-limiter** (`rate-limiter.ts`) — суточные лимиты платформ из
  `platform-limits.config.ts` (VK — 25 постов/сутки, spec). Упёрлись в лимит → канал
  `deferred`, задание не теряется и переобрабатывается `processDue()`.
- **адаптация контента** (`content-adapter.ts`, spec п.3) — отдельный слой трансформации
  под платформу (VK — 1 медиа на пост; длина текста — когда лимит задан).
- **публикаторы** (`publishers/`) — только официальные Bot API: Telegram через Bot API
  (реальная отправка при заданных токене и `chat_id`, иначе честный `skipped`); VK — через
  SMM-прослойку, прямой API не используется (spec п.3) → пока `skipped`.

Приоритет в очереди берётся из тарифа (Богатырский). In-memory очередь обрабатывает
«дозревшие» задания сразу; отложенные по времени ждут фонового воркера (BullMQ/Redis —
отдельный срез).

## Тарифы

| Тариф | Цена | Состав | Лимиты (в месяц) |
|---|---|---|---|
| Бесплатный | 0 ₽ | Контент-генерация + автопостинг с жёстким лимитом | 10 генераций · 10 постов · 1 канал |
| Лайт | 990 ₽/мес | + автоматизация (боты/воронки), 1 канал | 100 генераций · 100 постов · 1 канал |
| Богатырский | 1990 ₽/мес | + конструктор сайтов, аналитика, многоканальность, приоритет | 1000 генераций · ∞ постов · ∞ лендингов |

Цены и состав Лайта/Богатырского зафиксированы спецификацией. Решения заказчика вне spec
(подтверждены): автопостинг входит в Free с жёстким лимитом; **конструктор сайтов — только
Богатырский**; уровень лимитов — «сбалансированный». Всё это конфигурируется в
`tariff-catalog.config.ts` — единственном источнике правды.

## Запуск

```bash
cp .env.example .env      # заполнить при необходимости
npm install
npm run start:dev         # http://localhost:3000/api
```

Скрипты: `build`, `start`, `start:dev`, `start:prod`, `test`, `test:cov`, `lint`, `format`.

## Проверка прав (dev)

Аутентификации пока нет — тариф берётся из заголовка `x-tariff`
(**только для разработки**, см. `DevHeaderSubscriptionResolver`).

```bash
# Публичная витрина тарифов
curl localhost:3000/api/billing/tariffs

# Права текущей подписки
curl -H 'x-tariff: lite' localhost:3000/api/billing/me/entitlements

# Аналитика закрыта для Лайта → 403 с подсказкой availableOn
curl -i -H 'x-tariff: lite' -H 'content-type: application/json' \
  -d '{"funnel":{"clicks":100,"leads":0,"deals":0}}' \
  localhost:3000/api/analytics/diagnose

# Для Богатырского → 200 с диагностикой воронки
curl -H 'x-tariff: bogatyr' -H 'content-type: application/json' \
  -d '{"funnel":{"clicks":100,"leads":0,"deals":0}}' \
  localhost:3000/api/analytics/diagnose
```

## Соответствие 152-ФЗ (заложено в архитектуру)

- Хранение и обработка ПД — только в РФ-юрисдикции (Yandex Cloud / российский VPS).
  Реализации портов (учёт использования, БД) подключаются под РФ-хостинг.
- AI-вызовы маршрутизируются через единый шлюз с compliance-прослойкой
  (KodikRouter / ITGLOBAL AIaaS), без передачи данных за рубеж.
- `.env` с секретами не коммитится (см. `.gitignore`), в репозитории — только `.env.example`.
